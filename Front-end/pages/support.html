ศูนย์ช่วยเหลือและคำถามที่พบบ่อย (FAQ)

ค้นหาวิธีแก้ไขปัญหาเบื้องต้นเกี่ยวกับการใช้งานกระเป๋าเงินและมรดกดิจิทัล

ปัญหานี้มักเกิดจากการเชื่อมต่อ API อัตราแลกเปลี่ยนภายนอกเกิดความล่าช้า หรือเครือข่ายอินเทอร์เน็ตของท่านไม่เสถียร เบื้องต้นแนะนำให้ทดลองกดปุ่มรีเฟรช () บริเวณข้างนาฬิกาบนหน้าแดชบอร์ด หรือเว้นระยะเวลา 30 วินาทีเพื่อให้ระบบโหลดข้อมูลชุดใหม่ครับ

คำแนะนำนี้มีประโยชน์ต่อท่านหรือไม่?

ขอบคุณสำหรับข้อมูล โปรดเลือกเหตุผลเพื่อสถิติการปรับปรุงระบบ:

เนื่องจาก BBlockWallet ใช้ระบบความปลอดภัยความคุ้มครองสินทรัพย์แบบกระจายศูนย์ (Decentralized Wallet) ทางโปรเจกต์จะไม่มีการเก็บรหัสส่วนตัวใดๆ ไว้บนเซิร์ฟเวอร์หลัก หากท่านทำหาย จะไม่สามารถกู้คืนผ่านระบบได้ ท่านจำเป็นต้องใช้ **Seed Phrase (วลีสำรอง 12 คำ)** ที่บันทึกไว้ตอนสมัครนำมา Import เข้าสู่ระบบใหม่อีกครั้งครับ

คำแนะนำนี้มีประโยชน์ต่อท่านหรือไม่?

ขอบคุณสำหรับข้อมูล โปรดเลือกเหตุผลเพื่อสถิติการปรับปรุงระบบ:

ระบบทำงานในลักษณะ Smart Contract หรือสวิตช์ความปลอดภัยอัตโนมัติ (Dead Man's Switch) โดยผู้ใช้สามารถกำหนดระยะเวลาที่ระบบจะตรวจสอบการเข้าสู่ระบบ (เช่น 3 หรือ 6 เดือน) หากล่วงเลยระยะเวลาดังกล่าวและไม่มีการเคลื่อนไหว บัญชีและสินทรัพย์ดิจิทัลที่ระบุจะถูกส่งต่อไปยังที่อยู่กระเป๋าเงิน (Wallet Address) ของผู้รับสืบทอดที่ท่านตั้งค่าไว้ทันที

คำแนะนำนี้มีประโยชน์ต่อท่านหรือไม่?

ท่านสามารถคลิกเปลี่ยน วัน เดือน ปีเกิด ได้โดยการกดที่สัญลักษณ์ปฏิทินในหน้า Setting เมื่อท่านจิ้มเปลี่ยนวันเกิดแล้ว ระบบ JavaScript จะคำนวณเลขอายุใหม่ให้สัมพันธ์กับปีปัจจุบันโดยอัตโนมัติทันที ทั้งนี้หากท่านเปลี่ยนใจและยังไม่กดปุ่ม "ยืนยัน" เมื่อทำการปิดแท็บ ข้อมูลทั้งหมดจะถูกรีเซ็ตกลับเป็นค่าเดิมที่มีอยู่ในฐานข้อมูลเพื่อความปลอดภัยครับ

คำแนะนำนี้มีประโยชน์ต่อท่านหรือไม่?

ไม่มีผลกระทบต่อจำนวนสินทรัพย์คริปโตจริงของท่านครับ ฟังก์ชันปุ่มเฟืองในแดชบอร์ดหน้าสอง (หลังสลับปุ่มไข่ปลา) เป็นเพียงเครื่องมือคำนวณและแปลงค่าการแสดงผล (Fiat Conversion) เพื่ออำนวยความสะดวกในการเปรียบเทียบมูลทรัพย์สินในสกุลเงินสากลต่างๆ ตามอัตราแลกเปลี่ยนปัจจุบันเท่านั้น

คำแนะนำนี้มีประโยชน์ต่อท่านหรือไม่?

ไม่สามารถกู้คืนได้ครับ เนื่องจากการทำธุรกรรมบนระบบบล็อกเชนมีคุณสมบัติที่ไม่สามารถย้อนกลับหรือขอยกเลิกได้ (Irreversible) หากท่านโอนเหรียญผิดเครือข่าย สินทรัพย์นั้นจะหายไปอย่างถาวร โปรดระมัดระวังและตรวจสอบเงื่อนไขความสอดคล้องของ Network ปลายทางทุกครั้งก่อนยืนยันรายการ

คำแนะนำนี้มีประโยชน์ต่อท่านหรือไม่?

BBlockWallet ปฏิบัติตามมาตรฐานและกฎหมายคุ้มครองข้อมูลส่วนบุคคล (PDPA) อย่างเคร่งครัด ข้อมูลของท่าน (เช่น อีเมล, วันเกิด) จะถูกเข้ารหัสความปลอดภัยขั้นสูง และถูกนำไปประมวลผลเพื่อวัตถุประสงค์ในการยืนยันตัวตนและการเปิดฟังก์ชันการสืบทอดมมรดกเท่านั้น โดยไม่มีการเปิดเผยข้อมูลแก่บุคคลภายนอกเชิงพาณิชย์

คำแนะนำนี้มีประโยชน์ต่อท่านหรือไม่?

ในปัจจุบันแพลตฟอร์มไม่มีการเรียกเก็บค่าธรรมเนียมบริการใดๆ ทั้งสิ้นในการเปิดกระเป๋าเงินหรือตั้งค่าระบบมรดก อย่างไรก็ตาม การโอนเหรียญผ่านบล็อกเชนจริงในอนาคตจะมีค่าธรรมเนียมเครือข่าย (Gas Fee / Network Fee) ซึ่งถูกเรียกเก็บโดยเครือข่ายบล็อกเชนหลักนั้นๆ โดยตรง ไม่ใช่รายได้ของทางแพลตฟอร์มครับ

คำแนะนำนี้มีประโยชน์ต่อท่านหรือไม่?

แนะนำให้มีครับ เพื่อความสะดวกในการตรวจเช็กและกดเคลมรับสินทรัพย์ผ่านระบบอินเทอร์เฟซที่ปลอดภัย อย่างไรก็ดี หากท่านระบุเป็นที่อยู่กระเป๋าเงินภายนอก (External Wallet Address) สิทธิ์ในการโอนย้ายเหรียญเมื่อถึงกำหนดเวลาเงื่อนไขมรดกจะยังคงทำงานโอนผ่านที่อยู่นั้นได้เช่นเดียวกันครับ

คำแนะนำนี้มีประโยชน์ต่อท่านหรือไม่?

ปลอดภัยอย่างสมบูรณ์แบบครับ ข้อมูลสินทรัพย์ดิจิทัลทั้งหมดจะถูกจัดเก็บและผูกสิทธิ์อยู่บนบัญชีบัญชีแยกประเภทแบบกระจายศูนย์บล็อกเชน (Blockchain) การปิดหน้าจอหรือข้อผิดพลาดทางอุปกรณ์ปลายทางจะไม่ส่งผลเสียต่อมูลค่าเหรียญ ตราบใดที่ท่านยังคงจัดเก็บ Seed Phrase ไว้อย่างปลอดภัยในพื้นที่ออฟไลน์ครับ
